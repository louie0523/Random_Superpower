# Ashwing Drake Lite — free animated dragon

A free, game-ready version of the Ashwing Drake: a rigged wyvern that
stands and walks on its wing-hands.

- **Mesh:** 11,992 triangles (the full pack's LOD1), 4 bone influences per vertex
- **Rig:** the full 61-bone rig, with the same bone names as the full pack
- **Animation:** 6 clips at 30 fps: idle, walk (loops), roar, bite, takeoff, fly (loops)
- **Textures:** 2K base colour, normal and metallic/roughness, embedded in the files
- **Files:** `Ashwing_Drake_Lite.fbx` (Unity, Unreal) and `Ashwing_Drake_Lite.glb` (Godot, web, Blender)
- **Scale:** metres; 12 m wingspan

Unity: Rig → Generic, root node `root`. Unreal: import as a Skeletal Mesh.
Godot: drop in the .glb.
