현재 개발중인 게임 랜덤 능력자 배틀로얄입니다!

총 8~12인 PvP 멀티 플레이 게임으로

플레이어들은 각자 무작위 클래스를 획득합니다.

클래스는 라운드중 변하지 않는 능력이며, 스킬과 패시브를 제공합니다.

또한 매 부활시마다 '랜덤 능력'을 획득합니다.

랜덤 능력은 스킬, 패시브를 제공하며 판을 뒤흔드는 조커성이 강한 능력들로 가득합니다.

플레이어는 각자 클래스와 랜덤 능력을 가지고 다른 플레이어와 전투합니다.

플레이어들은 서로 처치하며 재화 '소울'을 얻고 상점에서 스킬 및 스텟을 강회시키거나, 무기를 강화시킬 수 있습니다.

재화 소울이 시간에 따라 일정 이상이면 성소를 밝혀 소울을 소모하여 승리할 수 있습니다!

이처럼 소울은 재화이자 승리 조건이며, 가장 중요한 재화입니다.
